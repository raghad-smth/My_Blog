# My Dream Blog – A Full-Stack Blog Web Application

Ever since I was a child growing up full of opinions and perspectives, it has been my dream to share my thoughts with the world. I’ve always wanted a space where I could write, express myself, and connect with others through ideas and stories.

This blog project is the realization of that dream. I built everything from scratch — the design, the layout, the server, the database — to create a space that feels like *me*.

---

## Features

- A fully responsive blog interface
- Clean, minimal, and user-friendly design
- Post and comment system powered by RESTful APIs
- Dynamic rendering of content
- Simple and intuitive layout for easy reading and interaction

---

##  Technologies Used

### Frontend:
- HTML5
- CSS3 (Media Queries for Responsiveness)
- JavaScript 

### Backend:
- Node.js
- Express.js

### Database:
- PostgreSQL

### Tools:
- Figma (for design planning)
- Freepik (for illustrations)
- Railway (for hosting)



## Final Note

This blog is more than just a project — it’s a piece of my heart. I hope you enjoy exploring it as much as I enjoyed building it.
